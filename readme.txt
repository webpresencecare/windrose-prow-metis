A child of Metis for the Windrose Suite: common color names, and a dark mode that follows the site's own style.

== Description ==

Windrose Prow for Metis keeps Metis's templates, template parts, patterns and fonts. It gives Metis the color names Ipsum and Twenty Twenty-Five share (base, contrast, accent-1, accent-3, accent-5, accent-6), so a style or a pattern made for one Windrose Prow theme fits the others.

Metis's Dark Mode switch shows the other scheme of the site's own style: dark for a light style, light for a dark one. Metis's gradients follow.

Styles: Metis's default and its six variations in the common names, each with its other scheme, and Open Sea (deep water blue on foam white, six soft accents).

Choosing a style copies its values into the site's saved styles: a later change to a style reaches a site when the style is chosen again.

Requires the Metis theme.

Warning: Metis is still in development. It has no release yet and changes almost every day: its color names, its Dark Mode switch or its styles can change at any time, and this theme may then show the wrong colors until it is adapted. Use it to try things out; for a live site, wait until Metis is released.
